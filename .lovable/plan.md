

# GradFrame — Premium Graduation Photography Landing Page

## Overview
A single-page, fully responsive landing page for GradFrame, a graduation photography service in Zacatecas. Premium design with navy/black + gold color scheme, serif headings (Playfair Display), and clean sans-serif body text (Inter).

## Sections to Build

### 1. Navbar
- Logo: "GF / GradFrame"
- Links: Home, Cuadros, Estolas, Testimonios — smooth-scroll to sections
- "Login" button styled with gold accent
- Mobile hamburger menu

### 2. Hero Section
- Full-width with gradient overlay on placeholder image
- Title: "Welcome to the GradFrame Experience"
- Subtitle: "Capturando la culminación de tu esfuerzo."
- Gold CTA button: "Ver Paquetes" → scrolls to packages

### 3. Main Package Card
- Featured card for "Paquete de tres sesiones" — $1,700 MXN/person
- Group quote note (8+ personas: Familiar, Temática, Gala)
- WhatsApp CTA button (green, primary style)

### 4. Add-ons Grid — "Personaliza tu Paquete"
- Cards for: Toga y Birrete ($150), Estola Personalizada ($450), Cuadros (Desde $1,000)
- Each with description about quality/memory preservation

### 5. Special Services
- Fotos de Título: UAZ $350, ITZ $400, Otras $580
- Fotos Impresas: $320
- Clean card or list layout

### 6. Booking Process — 3-Step Visual Guide
- Step 1: Elige modalidad (Presencial en Zacatecas o Meet en línea)
- Step 2: Selecciona fecha y hora
- Step 3: Espera confirmación vía WhatsApp
- Icons + numbered steps layout

### 7. FAQ Accordion
- Anticipación de reserva
- Políticas de anticipo (50%/50%)
- Límite de familiares (8-10 personas)

### 8. Footer
- © 2026 GradFrame
- Social media icons
- Floating WhatsApp "Chat with us" button (persistent across page)

## Design System
- **Colors**: Deep navy (#1a1f3d) primary, gold (#d4a843) accents, dark backgrounds with white text
- **Fonts**: Google Fonts — Playfair Display for headings, Inter for body
- **Components**: shadcn/ui Accordion for FAQ, Cards for packages, Button variants for CTAs
- **Responsive**: Mobile-first, hamburger nav, stacked cards on small screens
